# Did Claude Opus 5.5 get worse? — companion files

Files behind the Machine Room Tech video (November 2026).

- English: https://youtu.be/H6B2qTefbJ4
- Tamil: https://youtu.be/OmHqhftRxrI

- `RESEARCH.md`: every claim in the video with its source, date and whether it was read first-hand or via a secondary report.
- `RUNLOG.md`: the on-screen test, exactly as it was run (command, settings, questions, ground truth, results and its limits).
- `effort-test/effort_test.py`: the script. `python effort_test.py truth` computes the answers, `run 3 3` runs the 72 calls through the Claude Code CLI, `report` writes the table.
- `effort-test/questions.json`, `effort-test/RESULTS.md`: the questions with their computed answers, and the results.

Disclosure: the research and the video were made with Claude, which Anthropic makes. Not sponsored. Check the sources yourself.
