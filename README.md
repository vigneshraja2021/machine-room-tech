# Machine Room Tech

Companion files for the **Machine Room Tech** YouTube channel ([@machineroomtech](https://www.youtube.com/@machineroomtech)):
AI and tech — how it really works.

Each video gets its own folder with the scripts and commands used in it.

| Video | Folder |
|---|---|
| I Put an AI Brain Inside My PC (and You Can Too) | [`i-put-an-ai-brain-inside-my-pc`](i-put-an-ai-brain-inside-my-pc) — one-click local AI setup (Ollama) for Windows, macOS and Linux |
| VS Code + Ollama = FREE Copilot (Offline, No GPU) | [`vscode-ollama-free-copilot`](vscode-ollama-free-copilot) — offline AI autocomplete + chat in VS Code with Continue + Ollama, no GPU needed |
| Which AI Is Actually Best at Tamil? | [`which-ai-best-at-tamil`](which-ai-best-at-tamil) — the six Tamil prompts, all 30 answers and the blind scores (ChatGPT, Gemini, 3 offline models) |
| Claude Code Tutorial for Beginners: Build a Real App With Zero Coding | [`claude-code-who-pays-today`](claude-code-who-pays-today) — the app, every prompt from the video, and the timed free-route results |
| Is Claude Opus 5.5 Nerfed? Did Claude Get Worse? I Checked the Data | [`opus-55-fact-check`](opus-55-fact-check) — every source with dates, and the medium vs high effort test (script, questions, results) |

Always read a script before you run it. These are kept short on purpose so you can.
